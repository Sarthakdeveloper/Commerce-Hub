# Commerce Hub

A responsive starter website for a CBSE Class 11–12 Commerce learning project.

## Features
- Responsive dashboard and navigation
- Sample chapter browser with class/subject filters and search
- Links to find video lessons on YouTube
- Interactive multiple-choice quiz with explanations and local score tracking
- Starter revision sheets and print/save-as-PDF support
- Revision checklist saved in the current browser
- Official CBSE curriculum link

## Run locally
Open `index.html` in a modern browser. No build tools are required.

## Publish free with GitHub Pages
1. Create a public GitHub repository named `commerce-hub`.
2. Upload `index.html` and `README.md`.
3. Open repository Settings → Pages.
4. Choose deployment from the `main` branch and `/ (root)`, then Save.
5. Open the URL GitHub Pages provides.

## Important
This is a prototype, not a complete or officially endorsed CBSE course. Verify chapter lists and details against the current official syllabus before publishing educational claims. Replace sample notes with reviewed original material. Video links currently open YouTube search results rather than a specific creator's video. No student account data is collected; quiz and checklist progress are stored only in local browser storage.

The initial version uses no external libraries, backend or paid service.
